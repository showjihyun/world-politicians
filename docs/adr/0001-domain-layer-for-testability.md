# ADR 0001 — 순수 도메인 층을 분리해 단위 테스트를 가능하게 한다

- 상태: 채택
- 날짜: 2026-08-29

## 배경

이 저장소에는 단위 테스트가 하나도 없었다. 검증 수단은 Playwright E2E 53개가
전부였고, 그것도 브라우저를 띄워 약 90초가 걸린다.

테스트가 없어서가 아니라 **쓸 수 없어서** 없었다. 핵심 로직이 전부 순수 함수인데도
모듈 전역 상태에 묶여 있었다:

| 모듈 | 결합 |
| --- | --- |
| `src/lib/graph.ts` | `buildGraph()` 가 `RELATIONSHIPS` 를 직접 읽음 |
| `src/lib/timeline.ts` | `HISTORY_ARCS` 를 직접 읽고, `new Date()` 로 현재 월을 계산 |
| `scripts/news-pipeline/merge.mts` | 누적·선별 규칙이 `fs` 읽기/쓰기와 같은 함수 안에 있음 |
| `scripts/news-pipeline/fetch.mts` | 매체 허용 판정이 RSS 수집 코드와 한 몸 |

그래서 "관계 3개짜리 그래프", "2018년 8월 기준 시계열", "이 매체명은 통과해야 하는가"
같은 최소 입력으로 확인할 방법이 없었다. 확인하려면 전체 데이터셋을 로드하거나
네트워크를 타야 했다.

이 대가는 추상적이지 않았다. 이번 작업 기간에 나온 실제 사고들:

- 허용 목록의 `'AP'` 를 부분일치로 써서 CoinG**ap**e · Yahoo News Sing**ap**ore ·
  Tele**grap**hHerald 가 통과했다. 9건이 데이터에 들어와 있었고, README 의
  "이 매체에서만 수집한다" 는 서술이 거짓이 됐다.
- 파이프라인이 매 실행마다 결과를 덮어써서, 수집이 부실한 날 아카이브가
  239건 → 4건으로 잘렸다.
- 재처리가 `generatedAt` 을 갱신해, 화면 배지가 "2시간 전" 이라 표시했지만
  실제 데이터는 27.7시간 전 것이었다.
- 시계열이 창 시작 이전의 큐레이션 포인트를 이어받지 않아, 가장 중요한 반전
  (trump × musk) 이 화면에서 사라졌다.

넷 다 **순수 함수의 로직 오류**다. 브라우저도 네트워크도 필요 없이 잡을 수 있었다.

## 결정

의존 방향을 한쪽으로 고정한다. 도메인은 아무것도 모른다.

```
src/domain/          순수. 타입 외 런타임 import 없음
  graph.ts           그래프 구성 · 가시성 · 인사이트 · 회전 · 중심력
  timeline.ts        관계 시계열
scripts/news-pipeline/core.mts   누적 · 선별 · 파티션 · 매체 판정 · 수집시각 결정

src/lib/             어댑터. 도메인에 실제 데이터셋을 묶는다
scripts/news-pipeline/*.mts      어댑터. fs·network·process 를 맡는다
```

구체적으로 바꾼 것:

- `buildGraph(politicians)` → `buildGraph(politicians, relationships)`
- `buildPairTimeline(a, b, win, byPair)` → `(..., arcs, now = new Date())`
- 누적·선별·매체판정을 `core.mts` 로 옮기고, 기존 모듈은 그것을 호출만 한다

호출부는 바뀌지 않았다. `src/lib/graph.ts` 가 `export * from '../domain/graph'` 로
재수출하고 데이터셋을 묶은 `buildGraph` 만 덮어쓴다. 컴포넌트는 지금까지처럼
`../lib/graph` 에서 가져다 쓴다.

## 결과

- 단위 테스트 51개, **약 0.4초**. E2E 53개는 약 90초 — 200배 차이다.
- 위 사고 4건에 회귀 테스트를 붙였다. `core.test.mts` 는 CoinGape 를 포함한
  7개 매체명이 막히는지, 신규가 비어도 기존이 남는지, 재처리가 수집 시각을
  보존하는지를 고정한다.
- 도메인 테스트는 **파일시스템도 브라우저도 쓰지 않는다.** `vitest.config.ts` 의
  `environment: 'node'` 와 include 패턴이 그 경계를 강제한다.
- 시계열 테스트는 기준 시각을 주입하므로 달이 바뀌어도 깨지지 않는다.

## 대안과 기각 사유

**전면 재구성 (usecase/repository/entity 패키지 분리).** 이 규모(컴포넌트 14개,
파이프라인 스크립트 8개)에서는 층이 늘어난 만큼 얻는 게 없다. 실제로 막고 있던 것은
"순수 함수가 전역을 참조한다" 하나였고, 그것만 끊으면 테스트가 열린다.

**E2E 만 늘리기.** 위 4건 중 3건은 E2E 로 잡기 어렵다. 매체 허용 판정과 수집시각
보존은 화면에 드러나지 않고, 누적 소실은 다음 날 실행까지 가야 보인다.

**컴포넌트 렌더 테스트 도입.** 값은 있지만 지금 병목이 아니다. 이번에 난 사고는
전부 로직이었지 렌더가 아니었다. 필요해지면 그때 jsdom 을 얹는다.

## 지키는 방법

- `.github/workflows/ci.yml` 이 push·PR 마다 typecheck → 단위 테스트 → 빌드를 돌린다.
  CI 에 걸려 있지 않으면 "TDD 가능한 구조" 는 문서에만 존재한다.
- 도메인 파일이 `../data` 나 `node:fs` 를 import 하기 시작하면 경계가 깨진 것이다.
  리뷰에서 그것만 봐도 된다.
